🔑 OpenAI Voice Setup

This app uses OpenAI TTS for high-quality voice on every device. Your key is saved on this device only and sent exclusively to OpenAI.

How to get your key:
1. Go to platform.openai.com
2. Sign in → Profile → API Keys → Create new secret key
3. Make sure you have at least $5 credit in Billing
Key must start with sk- and be at least 20 characters
Cloudflare Worker URL (required for mobile):
Paste your Worker URL below — e.g. https://cpa-proxy.yourname.workers.dev
Leave blank on desktop (not needed there).
